# Модуль моделей даних (`server/src/models`)

Цей каталог містить Mongoose-схеми та моделі для взаємодії з базою даних **MongoDB**. Схеми забезпечують структурування даних, валідацію полів, створення індексів та зв'язок із TypeScript-інтерфейсами.

---

## Файли та моделі

| Файл | Модель Mongoose | Колекція в MongoDB | Опис |
| :--- | :--- | :--- | :--- |
| [`Post.ts`](/server/src/models/Post.ts) | `Post` | `posts` (за замовчуванням) | Публікації, новини та архівні матеріали бібліотеки |
| [`User.ts`](/server/src/models/User.ts) | `User` | `luhansk_library_accounts` | Облікові записи користувачів та адміністраторів |

---

## 1. Схема `Post` (`Post.ts`)

Модель описує публікацію (новину, статтю або архівний матеріал бібліотеки). Підтримує збереження як нових постів, так і мігрованого архівного вмісту зі старого сайту.

### Структура полів моделі:

| Поле | Тип Mongoose | Обов'язкове | Значення за замовчуванням / Опції | Опис |
| :--- | :--- | :---: | :--- | :--- |
| `title` | `String` | **Так** | — | Заголовок публікації |
| `shortDescription` | `String` | Ні | — | Короткий опис / анонс |
| `content` | `String` | **Так** | — | Повний вміст публікації (підтримується HTML) |
| `imageUrl` | `String` | Ні | — | Посилання на банер/обкладинку в Cloudinary |
| `category` | `String` | Ні | `'news'` | Категорія публікації |
| `viewsCount` | `Number` | Ні | `0` | Кількість переглядів |
| `tags` | `[String]` | Ні | — | Масив тегів для фільтрації |
| `author` | `String` | Ні | `'Admin'` | Автор допису |
| `oldId` | `Number` | Ні | `index: true` | Старий числовий ID з MySQL (для архівних постів, з індексом) |
| `seoKeywords` | `String` | Ні | — | Ключові слова для SEO |
| `seoDescription` | `String` | Ні | — | Мета-опис для SEO |
| `originalData` | `Schema.Types.Mixed` | Ні | — | Повний сирий JSON-об'єкт зі старого сайту |
| `createdAt` | `Date` | Ні | `Date.now` | Дата створення |
| `updatedAt` | `Date` | Ні | `Date.now` | Дата останнього оновлення |

---

## 2. Схема `User` (`User.ts`)

Модель описує користувача системи. Вона використовується для автентифікації, розмежування прав доступу (RBAC) та зберігання особистих даних читача/співробітника.

### Структура полів моделі:

| Поле | Тип Mongoose | Обов'язкове | Валідація / Enum / Опції | Опис |
| :--- | :--- | :---: | :--- | :--- |
| `firstName` | `String` | **Так** | — | Ім'я |
| `lastName` | `String` | **Так** | — | Прізвище |
| `patronymic` | `String` | Ні | — | По батькові |
| `email` | `String` | **Так** | `unique: true` | Унікальна електронна пошта (для логіну) |
| `phone` | `String` | **Так** | — | Номер телефону |
| `passwordHash` | `String` | **Так** | — | Хеш пароля (Bcrypt) |
| `dateOfBirth` | `Date` | **Так** | — | Дата народження |
| `gender` | `String` | **Так** | `enum: ["Male", "Female"]` | Стать користувача |
| `address` | `String` | **Так** | — | Адреса проживання |
| `education` | `String` | Ні | — | Освіта |
| `activitiField` | `String` | Ні | — | Сфера діяльності |
| `workplace` | `String` | Ні | — | Місце роботи / навчання |
| `addictionalInfo` | `String` | Ні | — | Додаткова інформація |
| `gdprConsent` | `Boolean` | **Так** | — | Згода на обробку персональних даних |
| `role` | `String` | Ні | `enum: ["user", "manager", "admin"]`, default: `'user'` | Роль користувача в системі |

### Налаштування схеми:
- **`timestamps: true`**: Mongoose автоматично керує полями `createdAt` та `updatedAt`.
- **`collection: "luhansk_library_accounts"`**: Явно вказана назва колекції в MongoDB.
