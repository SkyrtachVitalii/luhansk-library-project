# Сервісний шар (`server/src/services`)

Цей каталог містить **сервісний шар (Service Layer)**. Сервіси ізолюють складну бізнес-логіку від контролерів Express, взаємодіють з MongoDB через Mongoose-моделі, керують криптографією (хешуванням паролів) та генерацією JWT-токенів.

## Детальний опис `AuthService` (`auth.service.ts`)

Клас `AuthService` містить статичні методи для обробки процесів реєстрації та автентифікації.

### Конфігураційні параметри:
- **`JWT_SECRET`**: Береться з `process.env.JWT_SECRET` (або використовується резервне значення `'fallback_secret_key'`).
- **`JWT_EXPIRES_IN`**: Термін дії токена становить **7 днів** (`'7d'`).

---

### Методи класу `AuthService`:

#### 1. `register(data: any): Promise<IUser>`
Створення нового облікового запису з дотриманням правил безпеки.
- **Логіка**:
  1. Перевіряє, чи не існує вже користувач із вказаним `email` (`User.findOne({ email })`). Якщо існує — викидає помилку `User already exists with this email`.
  2. Генерує сіль `bcrypt.genSalt(10)` та хешує пароль `bcrypt.hash(data.password, salt)`.
  3. Створює об'єкт користувача, явним чином фільтруючи вхідні поля.
  4. **Безпека**: Поле `role` затиснено на значення `'user'` (підвищення ролі до `manager` чи `admin` можливе лише через БД/адмін-панель).
  5. Поле `gdprConsent` явним чином приводиться до булевого типу `Boolean(data.gdprConsent)`.
  6. Зберігає користувача у БД та повертає створення документу.

#### 2. `login(email, password): Promise<{ user: IUser, token: string }>`
Автентифікація користувача за логіном і паролем.
- **Логіка**:
  1. Шукає користувача в БД за `email`. Якщо не знайдено — викидає помилку `Invalid email or password`.
  2. Порівнює введений пароль із `passwordHash` за допомогою `bcrypt.compare(password, user.passwordHash)`. Якщо паролі не збігаються — викидає помилку `Invalid email or password`.
  3. Генерує JWT-токен за допомогою `jwt.sign`:
     ```typescript
     jwt.sign(
       { userId: user._id, role: user.role },
       JWT_SECRET,
       { expiresIn: '7d' }
     )
     ```
  4. Повертає об'єкт `{ user, token }`.

#### 3. `verifyToken(token: string): any`
Перевірка цілісності та терміну дії токена.
- **Логіка**:
  - Викликом `jwt.verify(token, JWT_SECRET)` розшифровує корисне навантаження (payload).
  - При виникненні помилки (прострочений токен або підроблений підпис) викидає виключення, яке перехоплюється у `auth.middleware.ts`.
