# UI Components (`client/src/components`)

Модуль містить набір реутилізовних React-компонентів, організованих за модульним принципом із використанням **SCSS Modules** та анімацій **GSAP**.

---

## 🎨 Принципи стилізації та анімацій

1. **Модульний SCSS (`*.module.scss`):** 
   Кожен компонент розташований у власній папці та ізолює свої стилі від глобального середовища. Усі кольори, фони, рамки та текстові відтінки прив'язані до системних та компонентних CSS-змінних (`var(...)`), визначених у `@layer base` (`:root` та `.dark`), без використання хардкодних Hex/RGB значень.
2. **GSAP Анімації:**
   Анімації (Preloader, плавність відкриття меню, інтерактивні ефекти) реалізовані через **GSAP v3**. Для захисту від витоку пам'яті під час ререндерингу обов'язково очищуються анімаційні контексти (`gsap.context()` або хук `@gsap/react`).

---

## 🧱 Ключові UI-компоненти

| Компонент | Призначення / Функціонал |
| :--- | :--- |
| **`Header/`** | Верхня шапка сайту, адаптивна мобільна шторка навігації `Sheet` (на базі `@base-ui/react/dialog` + Tailwind CSS із нативним закриттям по backdrop та Escape), кнопка входу/профілю, перемикач теми та доступності. |
| **`Footer/`** | Підвал сайту з контактами, корисними посиланнями та копірайтом. |
| **`Sidebar/`** & **`AsideMenu/`** | Бічне меню з рубриками, швидким доступом до каталогів бібліотеки. |
| **`PostList/`** | Список постів/новин із підтримкою пагінації та фільтрації за категоріями. |
| **`SingleOldPost/`** | Рендеринг окремого архівного поста, форматування дати та медіа-вкладень з Cloudinary. |
| **`SafeHTML/`** | Безпечний рендеринг збереженого HTML-вмісту з бази даних через `html-react-parser`. |
| **`Auth/`** (`LoginModal`) | Модальне вікно авторизації користувача через Express API. |
| **`AddNewUser/`** & **`AdminAllUsers/`** | Компоненти адмін-панелі для перегляду, додавання та видалення користувачів. |
| **`Preloader/`** | Анімований екран завантаження сайту з контролем мінімального часу показу. |
| **`Pagination/`** | Елемент пагінації для списків статей. |
| **`Socials/`** & **`SocialsHelp/`** | Блоки соцмереж та надання допомоги бібліотеці. |
| **`ToTopBtn/`** | Кнопка швидкої прокрутки сторінки догори. |
